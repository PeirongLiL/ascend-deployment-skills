# 当前服务启动计时

明确用户要服务启动、容器重建、主机重启还是断电冷启动；读取当前进程与 systemd/container 状态，检查是否允许停服。只做诊断或生成 Skill 不授权重启。

保存同一轮的服务启动、模型加载开始、权重加载结束、完整模型加载结束、引擎准备结束、API 首次就绪及首个成功请求时间。不要跨轮匹配日志，不将历史累计日志里的旧报错归到当前轮。

权重加载包含在完整模型加载内，不能重复相加。分布式并行 rank 耗时看关键路径/最慢有效 rank；不把 64 卡耗时求和。明确所有时间段的起止，未记录阶段留空。

记录编译缓存命中、文件页缓存条件、Prefix Cache、模型/权重哈希、上下文及并行配置；不能将缓存收益全部归因于加载代码优化。清页缓存、移动缓存目录或改参数均需符合任务授权。
